# QR Code Generator

A simple QR code generator web application that lets you generate QR codes from any text or URL.

## Features

- Generate QR codes from any text or URL
- Press **Enter** or click the **Generate QR Code** button to generate
- Clean, dark-themed UI

## Usage

Open `index.html` in a web browser, enter any text or URL in the input field, and click **Generate QR Code**.

## How It Works

QR codes are generated using the free [QR Server API](https://goqr.me/api/).
